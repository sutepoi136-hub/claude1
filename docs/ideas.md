# PMO練習アプリ アイデアメモ

## コンセプト
PMO業務を「ゲーム形式」で練習できるアプリ。メンバーズ等でキャリアを始めた人が、PMO・PM・企画職などへ広げるための実務スキルを鍛える。第1弾が **議事録クエスト**。

## 議事録クエスト(v2)の方針
- **AIを使わない**(無料で遊べること)。採点は決まった基準で、毎回同じ結果。書き方の揺れには、正規化(日付・時刻・数字・全角)と同義語で対応する。
- **2つの物語**: 仕事編(リアル重視のAX案件)と魔王軍編(ドラマ重視のファンタジー)。どちらも全12話の構成を先に決め、配信は各難易度2〜3話から。残りは後から穴埋めする。
- 会議は「決定・ToDo・保留・次回」の形を必ず保つ。会議の途中で無関係な話題に脱線させない(冒頭のあいさつ程度は可)。
- 引っかけの型: 訂正された数字 / 保留を決定と書く / 撤回・変更された案 / 担当の変更 / 条件付きの決定 / 事実と推測の混同。
- サーバー不要・`index.html` をダブルクリックで遊べること。

## 実装状況(v2)
- [x] 採点エンジン(網羅・分類・ToDo・正確性・構成)、自動の赤ペン、台本へのジャンプ、引っかけの解説
- [x] 仕事編・魔王軍編ともに全12話
- [x] 物語の画面(章・全話の年表・登場人物・プロローグ・その後)、話の解放
- [x] 会議室(オンライン会議風/作戦室風)、途中参加・退席、一時停止、速さ、字幕、メモ欄、自動保存
- [x] XP・レベル・連続日数・バッジ19種、テンプレート(旧版から引き継ぎ)
- [x] BGM(ホーム・仕事編・魔王軍編・魔王軍編第3章の4曲)、会議中の環境音、効果音。すべてその場で合成
- [x] 実力の推移(難易度・字幕・再挑戦をならした実力換算)、難易度ボーナス
- [ ] 上級の「1回だけ聞ける」本番モード、デイリーミッション
- [ ] より自然な音声(クラウドTTSで作った音声ファイルを同梱するなど)
- [ ] 第3の物語(例: 自治体DX、病院の電子カルテ刷新、ゲーム開発の炎上案件)
