# PMO練習アプリ アイデアメモ

## コンセプト
PMO業務を「ゲーム形式」で練習できるアプリ。メンバーズ等でキャリアを始めた人が、PMO・PM・企画職などへ広げるための実務スキルを鍛える。

## 共通基盤(将来)
- **スコア履歴**: ゲームごとの得点・日時・評価内訳を保存
- **成長グラフ**: スコアの推移を時系列で可視化
- **スキルレーダー**: 進捗管理 / リスク管理 / 調整力 / 文書化 / ファシリテーション
- 難易度(初級→中級→上級)、レベル、バッジ、週次チャレンジ、他ユーザーとの比較
- ユーザー管理(他の人にも使ってもらう場合)

## ゲーム案
| ID | ゲーム | 概要 | 評価ポイント |
|---|---|---|---|
| ★1 | **議事録作成**(MVP・着手中) | 約5分の会議音声を聞いて議事録を作成 | 決定事項・ToDo・課題の網羅、正確性、構造化 |
| A | スケジュール炎上シミュレーター | WBSと進捗に遅延・離脱イベントが発生。打ち手を選ぶ | 納期・品質・コストのスコア |
| B | リスク洗い出しクイズ | 計画書を読んで制限時間内にリスクを列挙 | 網羅性、確率×影響度、対策案 |
| C | エスカレーション練習 | AIが不機嫌なクライアント/忙しい上司役のチャット | 結論ファースト、事実と推測の分離、選択肢提示 |
| D | 進捗レポート作成 | 散らばった報告(Slack/メール風)を週次レポートに統合 | 取捨選択、RAG(赤黄青)判断 |
| E | 課題管理表の整理 | 粗い課題リストの担当/期限/優先度を整える | 重複統合、抜け補完の正確さ |
| F | ファシリテーション練習 | 脱線する会議をAI参加者相手に進行 | 時間管理、論点の戻し方、結論の引き出し |
| G | ステークホルダー調整パズル | 利害対立する関係者の落としどころを提案 | 要望整理、合意形成案 |
| H | 見積り・工数レビュー | ずさんな見積書の問題点を見つける | バッファ、タスク漏れ、前提不明 |
| I | 用語・フレームワーク学習 | PMBOK・アジャイル等をカード/4択で | 正答率 |

## 開発ロードマップ
1. 議事録ゲームのMVP(シナリオ + 音声再生 + 採点 + 履歴)
2. LLM(Claude API)による採点へ置き換え、シナリオ追加
3. D(進捗レポート)・E(課題管理表)など、テキスト入力+採点の再利用
4. C・F などAI対話型
5. 共通基盤(スコア履歴・成長グラフ・スキルレーダー)の本格化

## 議事録ゲームの設計メモ
- 会議は台本から作る → 正解データ(決定事項/ToDo/課題)を台本と一緒に管理できる
- 音声はTTSで生成(MVPはブラウザのSpeech Synthesis)
- 引っかけ要素: 「決まっていないのに決まったように聞こえる発言」「保留・持ち越し」
- 難易度調整: 話者数、脱線、専門用語、結論が最後に出る構成
