# PMO練習アプリ アイデアメモ

## コンセプト
PMO業務を「ゲーム形式」で練習できるアプリ。メンバーズ等でキャリアを始めた人が、PMO・PM・企画職などへ広げるための実務スキルを鍛える。

## 共通基盤(将来)
- **スコア履歴**: ゲームごとの得点・日時・評価内訳を保存
- **成長グラフ**: スコアの推移を時系列で可視化
- **スキルレーダー**: 進捗管理 / リスク管理 / 調整力 / 文書化 / ファシリテーション
- 難易度(初級→中級→上級)、レベル、バッジ、週次チャレンジ、他ユーザーとの比較
- ユーザー管理(他の人にも使ってもらう場合)

## 魔王軍編(ファンタジー・ストーリー連動シナリオ)

### ユーザー要望(忘れないこと)
- 実務の会議だけでなく、**魔王軍 vs 勇者軍の「魔王軍の中の会議」**のようなファンタジーも入れたい。ただし**議事録の練習になるよう、決定事項が決まり、次の行動が決まる会議の形は保つ**(その範囲で自由に)。
- 【**将来構想・今すぐではない**】シナリオに**時系列と一貫性**を持たせる。ステージが進むほど戦いも進む。最初は開戦前の**キックオフ会議** → 戦いの**準備の会議** → 具体的な作戦会議 → **終結間際の会議**、と時系列で並べ、会議内容を順に追うだけで物語も追える楽しみ方にする。最終的にそうしたシナリオ群を作る。

## シナリオ作成方針
- フィラー(えーと・あのー)、言い直し、聞き直し、遅刻者の合流など「人間らしさ」は入れる
- **会議の途中で全く別の話題に脱線する流れは入れない**(ユーザー要望)。冒頭のあいさつ程度の雑談はOK

## 議事録ゲームの設計メモ
- 会議は台本から作る → 正解データ(決定事項/ToDo/課題)を台本と一緒に管理できる
- 音声はTTSで生成(MVPはブラウザのSpeech Synthesis)
- 引っかけ要素: 「決まっていないのに決まったように聞こえる発言」「保留・持ち越し」
- 難易度調整: 話者数、脱線、専門用語、結論が最後に出る構成
