# 仕事編「青葉ライフ CS AXプロジェクト」設定資料

> 新しい話を書く・直すときは、この資料と矛盾させないこと。数字・日付・人物の口調を変える場合は、この資料を先に直す。
> 方針: **とにかくリアルに**。2026年の日本で実際にありそうな生成AI導入(AX)案件の会議を、PMOの目線で記録する。

## 1. 舞台

### クライアント: 青葉ライフ株式会社(あおばライフ)
- 埼玉県さいたま市に本社。1978年創業のカタログ通販が祖業。現在は日用品・食品の定期便「あおばの定期便」が主力。
- 売上 約320億円 / 従業員 約900名 / 会員 約80万人(うち定期便 約22万人)。
- **カスタマーサポートセンター(CSセンター)**: さいたま本社 70席 + 外部委託(東北コールサービス・仙台)50席 = **120席**。
- 問い合わせ: 電話 月 約4.5万件、メール 月 約1.8万件。
- 2026年秋の課題: 電話の**応答率78%**(目標90%) / 通話後の記録作業(**ACW**)平均**4分30秒** / メール1件の処理時間 平均**12分** / オペレーターの離職率 年30% / 社内FAQ **1,200件**のうち約3割(**360件**)が1年以上未更新(委託先向け手順書を含めると約400件)。
- **5年前(2021年)の失敗**: 顧客向けチャットボットを導入 → 回答がずれて苦情が増え、半年で停止。謝っていたのはオペレーター。当時の責任者は高木(当時CS部長)。
- 返品の受付期限: **商品到着後8日以内**(2023年の改定前は「30日以内」)。
- 委託先向け手順書: 約120件。委託先で毎年4月に見直している(が、返品期限の改定は反映されていなかった)。

### 支援会社: 株式会社ブリッジワークス
- ITコンサル・デジタル支援。PM・AIエンジニア・PMOを派遣。**プレイヤー(あなた)はここのPMO**。

## 5. その後(チャット)の書き方
- 会議の「その後」は、Teams/Slack風のチャット(`kind: 'chat'`)。`to: 'DM'` はあなたへのDM、`'#cs-ax-pj'` はプロジェクトのチャンネル。
- 会議で保留になったことの結果や、次の話への伏線をここで見せる(例: 第3話のあとに「当時の責任者が誰だったか、今はまだ言わないでおくね」)。

## 6. 表記・読み上げの約束
- 台本の数字は算用数字(「10月13日」「4分30秒」「1,350件」)。時刻は「10時」「14時」(「10:00」は読み上げが不自然なので台本では使わない)。
- 英字の略語は `series.js` の `readings` に読みを登録する(ACW→エーシーダブリュー、PoC→ポック など)。
- プレイヤーへの呼びかけは `{player}`(画面では名前、音声では読みに置き換わる)。
