# PMO練習アプリ

PMO業務をゲーム形式で練習するアプリ。第1弾は **議事録作成ゲーム**。

- アイデア・ロードマップ: [docs/ideas.md](docs/ideas.md)

## 議事録ゲーム(MVP)

会議音声(ブラウザのSpeech Synthesisで台本を読み上げ)を聞き、議事録を書いて採点を受けます。再生は2回まで。

### 動かし方
ビルド不要の静的アプリです。

```sh
python3 -m http.server 8000   # http://localhost:8000 を開く
```
音声再生は日本語音声に対応したブラウザ(Chrome / Edge / Safari 推奨)が必要です。

### 採点(100点)
| 項目 | 配点 | 内容 |
|---|---|---|
| 網羅性 | 70 | 決定事項・ToDo・課題・次回予定の要点をどれだけ拾えたか |
| 構造化 | 15 | 箇条書き・カテゴリ分けができているか |
| 正確性 | 15 | 「保留を決定と書く」などの引っかけに乗っていないか |

MVPはキーワード判定です。`js/scoring.js` の `evaluate()` を、Claude API等によるLLM採点に差し替える想定です。

### シナリオの追加
`js/scenarios.js` に台本(`script`)・要点(`keyPoints`)・引っかけ(`traps`)を追加します。

### 保存
スコア履歴はブラウザの `localStorage` に保存され、トップ画面に成長グラフ(簡易版)が出ます。
