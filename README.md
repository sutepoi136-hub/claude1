# 議事録クエスト

会議の音声を聞いて、議事録を書く。PMO・PMの「書く力」を鍛える練習ゲームです。
決まったこと、まだ決まっていないこと、誰が・何を・いつまでに——を書き分けて、採点を受けます。

- アイデア・ロードマップ: [docs/ideas.md](docs/ideas.md)
- 物語の設定資料: [仕事編](docs/story-work.md) / [魔王軍編](docs/story-maou.md)
- シナリオの追加方法: [docs/authoring.md](docs/authoring.md)

## 遊び方
1. フォルダの **`index.html` をダブルクリック**して、ブラウザで開く(サーバーもインストールも不要。Node.js も要りません)
2. 名前を入れて「はじめる」→ 物語を選び、会議に挑戦

- おすすめのブラウザは **Microsoft Edge**(自然な日本語の音声 Nanami・Keita などが使えることが多い)。Chrome でも遊べます。
- 会議の音声とBGMが出ます。音量にご注意ください(画面右上のスピーカーで、BGM・効果音をまとめて消せます)。
- 記録はブラウザの中に保存されます(別のブラウザ・パソコンには引き継がれません)。

## 2つの物語(全12話ずつ・配信中は各7話)
| | 仕事編「青葉ライフ CS AXプロジェクト」 | 魔王軍編「魔王城の書記官」 |
|---|---|---|
| あらすじ | 通販会社のコールセンターに生成AIを入れるAX案件。キックオフからPoC、社長の「前倒し」、パイロットでの誤案内事故、全席展開をかけた経営会議まで | 「魔王軍が村を焼いた」と勇者が攻めてくる。だが魔王は「勇者を殺すな」と命じた——。焼かれた村の真相、軍の中の内通者、そして和平へ |
| あなた | 支援会社のPMO(会議で名前を呼ばれ、ToDoも振られる) | 新任の書記官(最後の議事録が和平協定の原本になる) |
| 初級(第1章) | 第1話 キックオフ / 第2話 データとセキュリティ / 第3話 現場の声 | 第1話 緊急軍議 / 第2話 黒き森の罠 / 第3話 焼かれた村 |
| 中級(第2章) | 第5話 PoC中間報告 / 第6話 社長の一声 | 第5話 森の陥落 / 第6話 疑心 |
| 上級(第3章) | 第10話 緊急対策会議 / 第11話 ステアリングコミッティ | 第11話 停戦会談 / 第12話 エルデア和平会議(最終話) |

- 各シリーズの第1話は最初から遊べ、クリア(60点以上)すると次の話が解放されます(⚙設定で全話解放も可)。
- クリアすると「その後」(仕事編はチャット、魔王軍編は情景)が読めます。未配信の話は、次の話の「これまでのあらすじ」で補われます。

## 会議の画面
- 仕事編はオンライン会議風、魔王軍編は作戦室風。話している人が光り、途中参加・退席も分かります。
- 再生は1つの会議につき2回まで。**一時停止**(`Esc`)・**話す速さ**の変更ができます。**字幕**をオンにすると聞き取りやすくなる代わりに、XPが半分になります。
- **メモ欄**(採点されない走り書き)と**議事録**(提出用)の2つのノート。書いた内容は自動保存されます。
- 議事録テンプレート(組み込み4種+自分で保存)。旧版で作ったマイテンプレートは自動で引き継ぎます。

## 採点(AIなし・毎回同じ結果)
| 観点 | 配点 | 見るところ |
|---|---|---|
| 網羅 | 40 | 会議の要点を書けたか(1行・箇条書き1つの中に、要点の中身がそろっているか) |
| 分類 | 15 | 決定は【決定事項】、ToDoは【ToDo】、未決は【保留・課題】に書けたか(見出しなしでも「〜に決定」「〜は保留」ならOK) |
| ToDo | 15 | ToDoごとに「担当者」と「期限」が同じ行にあるか |
| 正確性 | 20 | 引っかけ(訂正前の数字、保留を決定と書く、撤回された案、担当の取り違え など)に乗っていないか |
| 構成 | 10 | 見出し・基本情報(日時・参加者)・箇条書き・長さ |

- 書き方の揺れに強くしてあります: 「10月13日」「10/13」「十月十三日」、「15時」「午後3時」「15:00」、「60万円」「六十万円」などを同じものとして扱います。見出しも【】・■・##・＜＞・「決定事項:」など、いろいろな書き方を認識します。
- 結果画面: ランク(S≥90 / A≥75 / B≥60=クリア / C≥40 / D)、5観点のレーダー、**自動の赤ペン添削**(行ごとに印とコメント)、要点チェック(書けなかった要点の**台本の該当箇所にジャンプ**)、引っかけ(回避できたものも含めて解説)、模範解答との見比べ、台本。

## ゲーム要素
XP・レベル・称号(全11段階)、連続プレイ日数、バッジ19種(引っかけ回避、ToDoの番人、耳だけで、スピード書記、シリーズ制覇 など)、自己ベスト、紙吹雪。

## BGM・効果音
すべてブラウザの中で合成しています(音声ファイルなし・著作権の心配なし・`file://` でも鳴る)。ブラウザの決まりで、最初にクリックかキー入力をしてから鳴り始めます。

| 場面 | 音 |
|---|---|
| ホーム | 「書斎」 フェルトピアノとやわらかい和音 |
| 仕事編 | 「夕方のオフィス」 エレピとローファイのリズム。会議の出入りはオンライン会議の通知音 |
| 魔王軍編 | 「魔王城」 低く響く弦に、ハープ・金管・太鼓の 6/8 拍子。暗いけれど前へ進む冒険の曲。出入りは重い扉、開始は鐘 |
| 魔王軍編 第3章 | 「和平への道」 刻み続ける低弦と陣太鼓で緊張感を出し、最後に長調へ開く |
| 会議中 | 聞き取りの邪魔をしないよう曲は止め、部屋の環境音だけを小さく流す(空調とタイピング / 暖炉と風) |
| 結果 | 朱印の音 → 物語ごとのファンファーレ(Sランクは特別版、届かなかったときは静かな2音)→ 曲が戻る |

- 操作音は「紙と印」(紙をめくる・ペンが走る・朱印を押す)で統一しています。
- ⚙設定で BGM と効果音の音量を別々に変えられ、会議中の環境音もオフにできます。

## 開発
- 素の HTML / CSS / JavaScript(ビルド不要)。`file://` で開いても動くよう、モジュールではなく通常の `<script>` で読み込みます。
- フォルダ構成
  - `js/core/` … 文字の正規化(`text.js`)、議事録の解析(`parser.js`)、採点(`scorer.js`)、ゲーム要素(`game.js`)、保存とテンプレート(`store.js`)。画面に依存しない
  - `js/data/` … 物語とシナリオ(`work/`=仕事編、`maou/`=魔王軍編。1話1ファイル)
  - `js/ui/` … 画面(`app.js`)、読み上げ(`speech.js`)、音の土台と楽器(`audio.js`)、効果音(`sfx.js`)、BGMと環境音(`bgm.js`)、ルール説明(`help.js`)、アイコン(`icons.js`)
- テスト: `npm test`(Node.js 18以上。依存パッケージなし)。各話について「模範解答が100点」「別の書き方の解答が90点以上」「すべての引っかけが反応する」「要点の語が台本に出てくる」「話者・難易度・日付の整合」などを自動で確かめます。
