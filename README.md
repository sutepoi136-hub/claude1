# PMO練習アプリ

PMO業務をゲーム形式で練習するアプリ。第1弾は **議事録作成ゲーム**。

- アイデア・ロードマップ: [docs/ideas.md](docs/ideas.md)

## 議事録クエスト(議事録ゲーム)

会議音声(ブラウザの読み上げ)を聞き、議事録を書いて採点を受けます。再生は2回まで。

### 動かし方(ZIPをダウンロードした場合)
1. [Node.js](https://nodejs.org)(LTS版)をインストール
2. ZIPを展開し、**`start.bat`(Windows)をダブルクリック**。Mac / Linux はターミナルで `bash start.sh`
3. 自動で開くブラウザ(または黒い画面に表示された `http://localhost:8000`)で遊ぶ

> ⚠ `index.html` をダブルクリックで開いたり、`python -m http.server` で配信したりすると、AI採点だけは動きません(画面に診断と手順が出ます)。形式採点・ゲーム要素・テンプレートは、どの開き方でも動きます。

> Windows で黒い画面にエラーが出る場合は、`start.bat` を一度閉じ、**ZIPを展開し直した新しいフォルダ**で実行してください(`start.bat` は英語のみ・CRLF 改行で、文字化けしないようにしています)。初回は `npm install` が自動で走ります(インターネット接続が必要)。

### AI採点を使うには(APIキーの設定)
1. 初回の `start.bat` 実行で `.env` が作られます(なければ `.env.example` を `.env` にコピー)
2. `.env` をメモ帳で開き、`ANTHROPIC_API_KEY=` の右にAPIキーを書いて保存
3. 黒い画面を閉じ、`start.bat` をもう一度実行

- APIキーは**サーバー側だけ**で使い、ブラウザには渡しません。`.env` はGitに含まれません。
- `PMO_AI_MODEL`(既定 `claude-opus-5-5`)、`PORT`(既定 8000)も `.env` で変更できます。
- `PMO_MOCK_AI=1` を付けて起動すると、APIキー無しで画面確認ができます(固定のダミー応答)。
- コマンドで動かす場合: `npm install` → `npm start`、テストは `npm test`。

### ゲーム要素
- **レベルとXP**: 点数がそのままXPになり、初クリア+20、Sランク+30。レベルアップで称号が変化
- **連続プレイ日数 🔥**、**バッジ10種**(Sランク、ひっかけ回避、AI添削デビュー、全ステージ制覇など)
- 自己ベスト更新、ランクスタンプ、紙吹雪の演出

### 議事録テンプレート
- 組み込み3種のほか、**自分で書いた内容を名前を付けて保存**して使い回せます(「💾 いまの内容を保存」)
- 「⚙ 管理」から編集・削除、「新しいゲーム開始時に自動で入れる」既定の指定ができます
- 保存先はブラウザ(localStorage)です。ブラウザやパソコンを変えると引き継がれません

### 会議音声と話者表示
- 話者ごとに別の日本語音声を割り当て、足りない場合は声の高さ・速さで区別します(使える声はOS/ブラウザ依存)。
- 参加者のアイコンと名前を表示し、発言中の人が光ります。「字幕を表示」で難易度を下げられます。

### 採点
1. **形式採点(100点・毎回同じ結果)**: 網羅性70 / 構造化15 / 正確性15。キーワード判定。
2. **AIボーナス(−10〜+8点)**: 形式採点では拾えない部分の補正。
   - 言い換えで拾えている要点(+1/件、最大+4)、読みやすさ(−2〜+2)、ToDoの具体性(−2〜+2)、事実誤り(−2/件、最大−4)
3. **赤ペン添削**: 議事録の該当箇所に印を付け、一言コメントと改善案を表示
4. **模範解答**: 標準版(台本に同梱)と、AIが台本から作る版

AI採点のブレを抑える工夫: AIは自由な点数を付けず固定ルーブリックの整数評価だけを返し、合計はサーバーで計算 / ボーナスに上下限 / 「拾えている」と主張できるのは形式採点が落とした要点IDのみ / 赤ペンの引用は議事録に実在する文字列だけ採用 / 同じ入力はハッシュでキャッシュして再採点しても同じ結果。
AIが使えない場合(キー未設定・通信失敗)も形式採点だけで続行します。

### シナリオ(全8本)
| 難易度 | シナリオ |
|---|---|
| 初級 | Webサイトリニューアル定例 / 勤怠システム刷新キックオフ / アプリ開発 週次進捗 / 顧客向けセミナー準備 |
| 中級 | キャンペーンLP制作定例 / システム移行 Go/No-Go判断 / SNS広告 振り返り / ベンダー障害 対応 |

### シナリオの追加
初級は `js/scenarios-beginner.js`、中級は `js/scenarios-intermediate.js` に、台本(`script`)・要点(`keyPoints`)・引っかけ(`traps`)・模範解答(`modelAnswer`)を足します。`npm test` が、模範解答が満点・引っかけに掛からないこと、台本の話者の整合、長さの目安を自動で確認します。

### 保存
スコア履歴(AIボーナス反映後の最終点)はブラウザの `localStorage` に保存され、トップ画面に成長グラフ(簡易版)が出ます。
